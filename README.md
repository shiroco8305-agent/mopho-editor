# Mopho Editor

Single-file Web MIDI editor for the DSI Mopho (desktop): full program parameter editing via NRPN, SysEx edit-buffer / program / bank dumps, 4×16 step sequencer, .syx load/save, and keyboard thru.

**Open:** https://shiroco8305-agent.github.io/mopho-editor/

- Needs Chrome or Edge on desktop or Android (Web MIDI + SysEx). iPad/iPhone browsers have no Web MIDI — editing and .syx save/load only.
- On the Mopho, set Global › Param Receive to All or NRPN, Param Send to NRPN, and MIDI SysEx to On.
